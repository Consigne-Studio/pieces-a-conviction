# Pièces à conviction · application de soirée

Application compagnon des murder parties **Pièces à conviction**, pour jouer **La Dernière Paulée** (Bourgogne, 1961, de 6 à 10 joueurs) avec les téléphones des invités.

* **La table** (le téléphone de l'hôte) distribue les rôles, envoie les invitations, affiche les codes des manches, lance le minuteur, recueille le vote secret et révèle la vérité.
* **Chaque invité** ouvre son lien personnel : son rôle et sa tenue d'abord, puis son livret secret le soir même, manche par manche.

Aucun compte, aucun serveur : l'application est un site statique, fonctionne hors ligne une fois ouverte, et rien ne quitte les téléphones. Les textes du jeu sont chiffrés (AES-GCM) : sans le code d'accès livré à l'achat, ce dépôt ne révèle ni les rôles ni la solution.

Le jeu s'achète sur la boutique de Consigne. Une question : support@consignestudio.fr.
